## Week 2 - Bits and Bytes
- Bit is short for binary digit, represents either one of the two states (0 or 1)
- Byte is a group of 8 bits
- Binary numbers are numbers represented using base 2
- Memory types include Volatile and Non-volatile, volatile loses data when power is off, non-volatile retains without power

## Week 3 - Text Structure
- Early text structures in print and typewriting, ancient texts with commentary
- Modern examples like newspapers, ledgers and digital formats like JSON
- Lines are fundamental in coding and indentation helps with visual understanding
- Paragraphs important in html for text presentation
- Markdown uses simple syntax like \# Title, \## Subtitle, \_italic_
- HTML is more verbose than markdown using tags like ul, li, p, h1, etc

## Week 4 - Keyboards and Editors
- Standard 104 key layout, variants like split, vertical and ortholinear
- Layouts include QWERTY, AZERTY, Dvorak

## Week 5 - CLI
- CLI originated from teletype machines connected to computer, commands often typed and printed on paper
- Basic commands include ls, cd, cat, pwd, less, mv, mkdir, rm
- SSH is secure shell to connect securely
- SCP securely copies files between computers, SFTP is secure file transfer protocol
- WSL is subsystem for linux on windows
